# Vision — downloads

Installers and automatic updates for **Vision**, a personal AI assistant for macOS and Windows.
This repository only holds releases; there is no source code here.

**[Download the latest version →](https://github.com/ungstrup14-oss/vision-releases/releases/latest)**

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 and newer) | `Vision-x.y.z-arm64.dmg` |
| Windows | `Vision-Setup-x.y.z.exe` |

**Mac:** open the `.dmg` and drag Vision into Applications. The first time, macOS can't verify the app:
click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway** next to Vision.

**Windows:** if SmartScreen warns, click **More info → Run anyway**.
